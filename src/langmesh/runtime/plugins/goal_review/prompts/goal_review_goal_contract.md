Whether the formal goal and its minimum conditions already express the user's full
intended outcome.

- `complete` means the contract omits no condition currently known to be necessary. This
  does not mean the work is complete; the standing still depends on evidence and
  independent exploration.
- `needs_revision` means the contract is too narrow, omits necessary adjacent work, or
  would allow a shallow implementation to be declared complete. This requires an `unmet`
  standing. In `message`, tell the working session to call `update_goal` first, preserve
  the existing purpose and minimum conditions, and state every additional checkable
  condition in the natural message the user will see.
