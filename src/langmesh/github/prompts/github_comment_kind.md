Which of the two comments this call writes onto the acknowledgement.

- `progress` — a quick "here's where this is headed"; the acknowledgement updates in place and you keep working. This is the default. Keep it small.
- `reply` — the finish they can read in passing; the acknowledgement updates in place and the turn stops. A few bullets are fine when the answer is several things.

A short turn needs no `progress` call. Do not narrate every command. Until a `reply` lands, the turn is still open. Be tight, not empty.
